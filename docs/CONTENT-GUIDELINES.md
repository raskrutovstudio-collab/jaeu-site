# JAEU Content Policy

Этот документ — обязательная редакционная политика сайта и инструкция для AI-агентов.

## Master copy

1. Материал заказчика является master copy.
2. Нельзя сокращать, упрощать или рерайтить предоставленный текст без отдельной команды.
3. Профессиональную терминологию сохранять.
4. Для новых материалов ориентироваться на лексику и стилистику существующих материалов Ассоциации.
5. Не заменять отраслевые понятия бытовыми аналогами ради «простоты».
6. Не превращать экспертные материалы в маркетинговые тексты.
7. При недостатке исходных данных использовать `DATA_REQUIRED` / `SOURCE_TEXT_REQUIRED` вместо выдумывания фактов.
8. Любая существенная редактура исходного текста должна быть явно согласована.
9. Сохранять названия организаций, нормативных актов, отраслевых терминов и профессиональных понятий.
10. SEO-оптимизация не должна менять смысл исходного профессионального текста.

## Источники

Приоритет:

1. исходный текст заказчика, если он есть в проекте;
2. исходные файлы и данные, ранее добавленные в репозиторий;
3. git history предыдущих версий;
4. существующая версия текста, если оригинал восстановить невозможно.

Если оригинала нет — не сочинять отраслевой текст. Зафиксировать `SOURCE_TEXT_REQUIRED`.

## Допустимые правки без отдельной команды

- двойные пробелы;
- очевидные опечатки;
- неправильные переносы;
- однозначная сломанная пунктуация;
- HTML-разметка без изменения слов.

Смысл, терминология, обороты речи и профессиональная лексика заказчика должны сохраняться.

## Языки

Русский — исходная публикуемая версия отраслевых материалов.

Казахский и английский подставляются только из подтверждённого перевода заказчика. Если перевода нет, строка остаётся русской. Нельзя самостоятельно переводить восстановленный отраслевой текст «для полноты i18n».

При отсутствии утверждённого перевода профессионального материала нельзя автоматически переводить или пересказывать master-copy. Требуется официальный перевод заказчика.

## Форма

UI остаётся современным. Контент остаётся полным и отраслевым: длинный профессиональный материал не сокращают потому, что он «менее современный».
