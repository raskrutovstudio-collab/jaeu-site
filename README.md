# JAEU — новый сайт Ассоциации ювелиров ЕАЭС

Чистый мультиязычный сайт для `jaeu.kz`, разработанный отдельно от текущего LP Motor-прототипа.

## Стек

- Astro, статическая сборка;
- TypeScript;
- собственные CSS и компоненты без UI-фреймворка;
- языки: русский `/`, казахский `/kz/`, английский `/en/`;
- GitHub → статическая сборка → Plesk.

## Запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run check
npm run build
npm run preview
```

## Рабочая связка

- ChatGPT: архитектура, SEO, семантика, контент, ТЗ и QA;
- Google Stitch: визуальные концепции и макеты;
- Cursor: реализация по утверждённому ТЗ;
- GitHub: версии, ветки и контроль изменений;
- Plesk: production-хостинг после отдельного подтверждения.
